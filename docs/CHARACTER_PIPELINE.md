# Character Pipeline

## 1. Asset requirements

| Property | Target |
|---|---|
| Format | GLB (glTF 2.0 binary) |
| Triangle budget | 20,000–30,000 |
| Skinned meshes | 1 |
| Materials | 2–3 |
| Skeleton | 30–40 joints |
| Morph targets | 15 visemes + optional blink/expression shapes |
| Animations | 10 clips (see below) |
| Textures | KTX2/Basis Universal, 512–1024, mipmapped |
| File size | ≤ 6 MB preferred, hard limit 10 MB |
| Scale | 1 unit = 1 meter; character ~1.2–1.6 m tall |
| Orientation | Facing +Z in Blender, exported to Bevy’s forward convention |
| Rig | Human-readable bone names, no scaled bones, no constraints baked incorrectly |

The old PRD’s ≤5k triangles / ≤24 joints is too low for a premium expressive
character and is superseded.

## 2. Required visemes

| Index | Name | Shape |
|---:|---|---|
| 0 | `viseme_AA` | Wide open “ah” |
| 1 | `viseme_E` | Spread “eh/ee” |
| 2 | `viseme_I` | Slight spread “ih” |
| 3 | `viseme_O` | Rounded “oh” |
| 4 | `viseme_U` | Pursed “oo” |
| 5 | `viseme_M` | Lips closed “m/b/p” |
| 6 | `viseme_F` | Upper teeth on lower lip |
| 7 | `viseme_L` | Tongue up |
| 8 | `viseme_R` | Tongue curled |
| 9 | `viseme_S` | Teeth together |
| 10 | `viseme_SH` | Protruded “sh/ch/j” |
| 11 | `viseme_TH` | Tongue out |
| 12 | `viseme_W` | Rounded “w” |
| 13 | `viseme_REST` | Neutral |
| 14 | `viseme_BLINK` | Eyes closed |

All morph targets must share the same vertex count/topology. Weights are
normalized to `[0, 1]`. The Bevy loader resolves morph names, not hardcoded
indices.

## 3. Required clips

| Clip | Loop | Purpose |
|---|---|---|
| `idle` | Yes | Breathing, sway, subtle head motion |
| `listening` | Yes | Head tilt, attentive pose |
| `talking` | Yes | Body/head talk motion; mouth driven separately |
| `happy` | No | Celebration |
| `surprised` | No | Short reaction |
| `sad` | No | Short reaction |
| `angry` | No | Short reaction |
| `sleeping` | Yes | Slow breathing, closed eyes |
| `blink` | No | One blink cycle (if not morph-only) |
| `touch_head` | No | Head/ear reaction |
| `touch_body` | No | Belly/body reaction |

Clip names are stable API. Missing clips are asset errors, not silent fallbacks.

## 4. Blender pipeline

1. Install Blender 4.x LTS.
2. Build/import the base mesh.
3. Create the armature with a clean, human-readable hierarchy.
4. Skin with normalized weights; no unweighted vertices.
5. Create the 15 viseme shape keys on the face mesh.
6. Author the 10 animation clips using actions/NLA.
7. Bake constraints if necessary.
8. Export GLB with:
   - Apply modifiers (except armature) enabled.
   - Skin, morph targets, animations enabled.
   - No cameras/lights unless intentional.
   - Y-up conversion handled by the exporter.
9. Compress textures to KTX2/Basis.
10. Run `gltf-transform optimize` and `gltf-validator`.
11. Add `metadata.json` with display name, scale, clip/morph mapping.
12. Add a 512×512 `thumbnail.webp`.
13. Add the character to `assets/characters/index.json` only after validation.

## 5. Validation

Minimum checks:

- `gltf-validator` reports 0 errors.
- Exactly one skin, 30–40 joints.
- 15 visemes present with expected names.
- All required clips present.
- No NaN/Inf vertex positions or weights.
- No unweighted vertices.
- Texture dimensions power-of-two and ≤1024.
- File size within budget.
- On-device load test in Bevy.
- On-device morph test: each viseme reaches 1.0 and returns to 0.
- On-device animation test: every clip plays and loops/ends correctly.

## 6. Quality gate

A character is accepted only if:

- Silhouette and face read clearly at phone size.
- Eyes are expressive; blink is convincing.
- Mouth shapes are distinct and not grotesque.
- Idle motion is subtle and non-repetitive.
- Transitions do not pop.
- Materials look good under the studio lighting.
- Performance meets the frame budget on the target device.
- License/provenance is documented.

## 7. Licensing

- Original characters only, or a documented CC0/commercial license.
- Do not use Talking Tom assets or any protected character.
- Do not ship the current `cat`, `dino`, or `trex` GLBs without verified
  provenance; they are prototype assets.
- Keep source `.blend` files and licenses outside the APK.

The asset is a stylized original cat, not a protected character. It is a

gates. The generator is deterministic and committed so the asset can be
regenerated.

### Regenerate

```powershell
& "C:\Program Files\Blender Foundation\Blender 5.3\blender.exe" `
  --background --python tools\blender\create_tomiko.py
```

### Current limitations

- No KTX2 textures yet; materials are Principled BSDF solid colors.
- The viseme shapes are geometric approximations, not scanned blendshapes.
- Automatic weights can exceed four joint influences; the glTF exporter
  normalizes to four. This is acceptable for the first pass but should be
  cleaned up for the final asset.
- Blender reports a non-manifold/duplicate-shell warning for the joined stylized
  mesh. It exports correctly but should be cleaned before the final art pass.
