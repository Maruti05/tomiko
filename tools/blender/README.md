# Blender Character Pipeline

The first original Tomiko character is generated by `create_tomiko.py` using
Blender 5.3.

## Regenerate the asset

```powershell
& "C:\Program Files\Blender Foundation\Blender 5.3\blender.exe" `
  --background --python tools\blender\create_tomiko.py
```

Outputs:

```text
assets/characters/tomiko/character.glb
assets/characters/tomiko/thumbnail.png
assets/characters/tomiko/metadata.json
```

## What the script builds

- A stylized original cat from rounded meshes.
- One joined skinned mesh with 5 materials.
- 27-joint armature with automatic weights.
- 15 shape keys: `viseme_AA` through `viseme_REST` plus `viseme_BLINK`.
- 11 animation actions exported as named glTF clips.
- A 512×512 thumbnail render.
- Metadata mapping clip and morph names.

## Rules

- Shape keys must have value `0.0` before export. Blender can create them with
  value `1.0`, which makes the face look broken and exports nonzero default
  weights. The script explicitly resets them.
- Keep one character mesh. Capsule end caps and other helper meshes must be
  joined before skinning, or they export unskinned.
- Do not export cameras/lights into the game GLB.
- Validate the GLB after generation: one mesh, one skin, 27 joints, 15 morph
  targets, 11 animations, default weights all zero.
- The current asset is a first pass. Texture work (KTX2), weight cleanup, and
  shape refinement are follow-up tasks.
